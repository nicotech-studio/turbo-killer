# TurboKiller 1.1.1

## English

- Fixes a problem that prevented Turbo Boost from being disabled on some Intel Macs.
- Improves component checks and updating from older versions.
- Disable and restore have been verified on the affected Mac.

To update, quit TurboKiller, replace the copy in Applications and open it again. Allow background operation if prompted.

For Intel Macs running macOS 13 or later. Still experimental; compatibility with every configuration is not guaranteed. The App and background helper are Developer ID signed, but this version is not Apple-notarized. Keep SIP enabled.

## 简体中文

- 修复部分 Intel Mac 无法关闭 Turbo Boost 的问题。
- 完善所需组件的检查和旧版本升级处理。
- 已在受影响电脑上验证关闭与恢复功能。

升级时，先退出 TurboKiller，替换“应用程序”中的副本后重新打开。如有提示，允许后台运行。

适用于 macOS 13 或更新版本的 Intel Mac。目前仍处于实验阶段，不保证所有配置兼容。App 和后台组件已使用 Developer ID 签名，但版本未通过 Apple 公证。请保持 SIP 开启。
