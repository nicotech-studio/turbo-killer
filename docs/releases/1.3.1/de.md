- TurboKiller sucht während der Ausführung nach neuen Versionen. Unter **Einstellungen → Allgemein** lässt sich die automatische Suche deaktivieren. Unter **Einstellungen → Über** kann jederzeit manuell gesucht werden.
- Wenn ein Update verfügbar ist, können Sie im Updatefenster die Versionshinweise lesen, das Update installieren und TurboKiller erneut öffnen.
