## Установка

1. Откройте DMG и перетащите TurboKiller в «Программы».
2. Откройте приложение. При блокировке: Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.
3. При запросе разрешите работу в фоне и следуйте указаниям по одобрению расширения или перезагрузке.

Завершите TurboKiller и замените приложение в «Программах» версией из TurboKiller-1.2.0.dmg. Следуйте запросам разрешений или перезагрузки.

Приложение и служба подписаны Developer ID. Эта версия не нотарифицирована Apple, поэтому macOS может блокировать первый запуск. Скачивайте только из официального репозитория. Перед обновлением завершите старое приложение.

## Как пользоваться

Выберите «Отключить Turbo Boost», чтобы снизить нагрев и шум вентиляторов, и «Восстановить Turbo Boost», когда нужна производительность. Отключение может замедлить ресурсоёмкие задачи. Проверяйте состояние после переключения; при ошибке не нажимайте кнопку многократно.

Состояние видно на значке ветра в строке меню

## Примечания к выпуску · 1.2.0

- Постоянный значок ветра с монохромным индикатором: Turbo Boost включён, отключён или состояние неизвестно.
- Компактное окно состояния и управления; на неподдерживаемом Mac вместо него показано пояснение. Настройки и выход доступны всегда.
- 17 языковых версий приложения, сайта, README и этих примечаний, включая арабский и иврит с интерфейсом справа налево.
- Обновление состояния при запуске, пробуждении, после операций и периодически в фоне.

## Обратная связь

Экспериментальная программа, проверенная на некоторых Mac с Intel. Совместимость со всеми конфигурациями оборудования и macOS не гарантируется. Сообщайте о проблемах на GitHub, указав модель Mac, версии macOS и приложения, полный текст ошибки или снимок экрана. Сообщения об успешной работе тоже приветствуются.

## Разработчикам

Приложение SwiftUI в строке меню взаимодействует по XPC с привилегированной службой, которая загружает или выгружает встроенное устаревшее расширение ядра. Состояние отражает загрузку расширения, а не измерение частоты процессора. Откройте TurboKiller.xcodeproj в Xcode для сборки. Сохраняйте исторический пакет расширения без изменений.
